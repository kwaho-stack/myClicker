# MyClicker (Windows)

화면의 정해진 위치(버튼)를 **한 시간에 한 번, 매번 다른 랜덤한 시각에** 클릭해 주는 프로그램입니다.
**실제 마우스 커서가 버튼까지 움직여 가서 클릭**합니다. 직선이 아니라 살짝 휘어진 경로로, 사람처럼 속도를 줄였다 높였다 하며 움직여요.
설치할 것 없이 Windows에 기본으로 있는 PowerShell만으로 동작합니다.

## 사용법
1. `실행.bat`을 더블클릭합니다.
2. **동작 시간**을 고릅니다. 예: `7`시 ~ `18`시 → 7시대, 8시대, …, 17시대에 각각 한 번씩 클릭합니다(18시대는 제외).
   - `22`시 ~ `2`시처럼 자정을 넘는 범위도 됩니다. 시작과 끝을 같게 하면 하루 종일 동작합니다.
3. **[위치 지정]**을 누르고 **3초 안에 마우스를 누를 버튼 위에 올려 두면** 그 좌표가 저장됩니다.
4. 필요하면 **[테스트 클릭]**으로 제대로 눌리는지 확인합니다.
5. **[시작]**을 누릅니다. 창에 다음 클릭 예정 시각과 기록이 표시됩니다.
   - 멈추려면 **[정지]**를 누르거나 창을 닫으면 됩니다.

## 클릭 시각이 정해지는 방식
- 한 시간대(예: 7:00~7:59)마다 **딱 한 번**, 랜덤한 시각(초 단위까지)에 누릅니다.
- 시간의 **끝부분(xx:55~59)과 시작부분(xx:00~04)이 더 자주** 뽑힙니다.
  특히 직전 클릭이 끝부분이었으면 다음 클릭은 60% 확률로 시작부분에 잡혀서,
  **"7시 58분 클릭 → 8시 1분 클릭"** 같은 효율적인 패턴이 자주 나옵니다.
- 두 클릭 사이는 최소 90초 이상 띄웁니다.
- 확률이나 구간 길이는 `MyClicker.ps1` 맨 위의 숫자를 바꾸면 조절할 수 있습니다.

| 설정 | 기본값 | 의미 |
|---|---|---|
| `$EDGE_MIN` | 5 | 경계 구간 길이(분) |
| `$P_END` | 0.35 | 마지막 5분에 누를 확률 |
| `$P_START` | 0.15 | 처음 5분에 누를 확률 |
| `$P_START_AFTER_END` | 0.60 | 직전 클릭이 끝부분이었을 때, 이번에 처음 5분에 누를 확률 |
| `$MIN_GAP_SEC` | 90 | 연속된 두 클릭 사이의 최소 간격(초) |

## 옵션
- **위치 흔들림 ±N 픽셀**: 매번 정확히 같은 점이 아니라, 지정한 위치 주변을 조금씩 다르게 누릅니다(기본 ±3).
- **매일 반복**: 켜면 매일 같은 시간대에 계속 동작하고, 끄면 이번 범위만 하고 자동으로 멈춥니다.
- **클릭 후 원래 위치로**: 클릭하고 나면 마우스를 원래 있던 자리로 되돌립니다.

## 주의
- 실제 마우스를 움직이기 때문에 **클릭할 때 대상 버튼이 화면에 보여야 합니다.** 창을 최소화하거나 다른 창으로 가리지 마세요.
- 동작하는 동안에는 **PC와 화면이 절전 모드로 들어가지 않도록** 자동으로 막아 둡니다.
  하지만 **화면 잠금(Win+L)** 상태나 PC를 직접 끈 상태에서는 클릭할 수 없습니다.
- PC가 꺼져 있어서 어떤 시간대를 통째로 놓치면 기록에 "놓침"으로 남기고 다음 시간대로 넘어갑니다.
- 화면 배율(125%, 150%)이나 모니터 위치가 바뀌면 **위치를 다시 지정**해 주세요.
- 기록은 `%LOCALAPPDATA%\MyClicker\log.txt`에도 저장됩니다.

| `실행.bat` | 더블클릭용 실행기 |
